# Foto usaha dan percakapan warga

Arahan pengguna menggantikan batas lama tanpa unggah, teks bebas, dan DM.

- Foto JPG/PNG/WebP maksimal 5 MB dan 16 megapiksel, diubah ke JPEG maksimal 1280px. Foto dibatasi pemilik pada mutasi ruko/lapak. Foto lama dipertahankan agar referensi lapak tidak terputus.
- Chat publik menerima 280 karakter, tetap memakai autentikasi, kanal gang dan jeda kirim. Bubble Alun-Alun muncul selama delapan detik untuk pesan baru pada figur yang dirender. Inbox pribadi tidak muncul sebagai bubble publik.
- Saat keliling, warga terdekat dalam 110 unit memunculkan tombol bicara. Inbox menampilkan 50 pesan terakhir pengirim/penerima dan diperbarui saat panel terbuka.
- KTP memisahkan identitas, figur, dan palet. Warna kertas/navy/kuning mengikuti desa; tombol kuning menunjukkan aksi utama, jarak dan label memperjelas formulir.

Validasi: chat lama 64/64 setelah ekspektasi lingkup diperbarui; chat/inbox 10/10; dunia/bubble/kedekatan 5/5; upload melalui runtime GD 5/5; pemulihan 13/13; bentuk KTP 19/19. KTP 360/1440px tanpa overflow/pageerror, screenshot diperiksa.

Batas: posisi figur warga merupakan simulasi desa, belum posisi pemain langsung lintas perangkat. Bubble saat ini untuk Alun-Alun pada peta 3D. Inbox memiliki notifikasi dan tanda belum dibaca, tetapi belum menyediakan blokir. Foto lama belum dibersihkan otomatis.
